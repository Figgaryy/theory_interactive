S1 · De Morgan ข้อสองเซต

สไลด์ Ch.1 หน้า 13 · ใกล้เคียงข้อสอบ: ชุด 1 ข้อ 2(d), ชุด 2 ข้อ 1(c), ชุด 4 ข้อ 19
โจทย์: Prove that A \ (B ∩ C) = (A \ B) ∪ (A \ C). (อาจารย์เขียนกำกับว่า EASY)

แปลโจทย์

"เอาออกจาก A เฉพาะสิ่งที่อยู่ทั้งใน B และ C" เท่ากับ "เอาออกจาก A สิ่งที่อยู่ใน B, รวมกับ เอาออกจาก A สิ่งที่อยู่ใน C". สมาชิกที่รอดใน A คือตัวที่ ไม่อยู่ใน B∩C = ไม่อยู่ใน B หรือ ไม่อยู่ใน C.

วิธีที่ 1 — ใช้กฎแบบสไลด์หน้า 13 (เขียนเป็นสายเท่ากับ)

  1. A \ (B ∩ C) = A ∩ B ∩ C — กฎ X \ Y = X ∩ Ȳ
  2. = A ∩ (B̄ ∪ C̄) — De Morgan ของ complement: B ∩ C = B̄ ∪ C̄
  3. = (A ∩ B̄) ∪ (A ∩ C̄) — กฎกระจาย ∩ เข้า ∪
  4. = (A \ B) ∪ (A \ C) — กฎ X \ Y = X ∩ Ȳ ย้อนกลับ ∎

วิธีที่ 2 — double inclusion (เขียนส่งได้)

(⊆) Let x ∈ A \ (B ∩ C). Then x ∈ A and x ∉ B ∩ C, i.e. x ∉ B or x ∉ C. If x ∉ B then x ∈ A \ B; otherwise x ∈ A \ C. Either way x ∈ (A \ B) ∪ (A \ C).
(⊇) Let x ∈ (A \ B) ∪ (A \ C). Then x ∈ A, and x ∉ B or x ∉ C; hence x ∉ B ∩ C, so x ∈ A \ (B ∩ C). ∎

จุดที่มักพลาด

  • สลับ ∪ กับ ∩ ผิดข้าง: กฎคือ "ลบ ∩ ได้ ∪" และ "ลบ ∪ ได้ ∩" (A \ (B ∪ C) = (A\B) ∩ (A\C) คือข้อแรกในสไลด์)
  • ตรวจเร็ว: A={1,2,3}, B={1,2}, C={2,3}: ซ้าย = A\{2} = {1,3}; ขวา = {3} ∪ {1} = {1,3} ✓

S2 · นับจำนวนฟังก์ชันฟังก์ชัน

สไลด์ Ch.1 หน้า 20 · ใกล้เคียงข้อสอบ: ชุด 4 ข้อ 5.3, 5.4
โจทย์: (1) If A = ∅, how many functions are there from A to B? (2) If B = ∅, how many functions from A to B? (3) If A contains exactly one element, how many functions from A to B?

หลัก

ฟังก์ชัน f : A → B = เซตของคู่ (a, f(a)) ที่ทุก a ∈ A มีคู่พอดี 1 คู่. แต่ละ a เลือกปลายทางได้ |B| แบบ อิสระต่อกัน → จำนวนฟังก์ชัน = |B||A| (textbook Problem 1.5.4).

  1. A = ∅: ไม่มี a ให้จับคู่ → เซตของคู่ที่ว่างเปล่า ∅ เป็นฟังก์ชันที่ถูกต้อง (เงื่อนไข "ทุก a ∈ A มีคู่" จริงโดยว่างเปล่า) และเป็นตัวเดียว → 1 ฟังก์ชัน (สูตร |B|⁰ = 1 แม้ B = ∅: 0⁰ = 1 ในบริบทนี้)
  2. B = ∅, A ≠ ∅: ต้องมีคู่ (a, b) สำหรับ a ∈ A แต่ไม่มี b ให้เลือก → 0 ฟังก์ชัน (0|A| = 0). (ถ้า A = ∅ ด้วย กลับไปข้อ 1 = 1)
  3. |A| = 1, A = {a}: ต้องเลือก f(a) ∈ B ได้ |B| แบบ → |B| ฟังก์ชัน (|B|¹) — ถ้า B = ∅ ก็ 0
สังเกต: ทิศทางสำคัญ — "จาก ∅" มี 1, "ไป ∅" มี 0. ชุด 4 ข้อ 5.4 ถามแบบ "ไป ∅" ตอบ 0. อาจารย์เขียนใต้สไลด์ว่าให้ลองวาด mapping ดู.

S3 · inverse ของ bijection เป็น bijectionฟังก์ชัน

สไลด์ Ch.1 หน้า 26 · ใกล้เคียงข้อสอบ: ชุด 1 ข้อ 4, ชุด 2 ข้อ 4
โจทย์: Show that if f : A → B is a bijection, then f⁻¹ is also a bijection from B to A.

แปลโจทย์

f⁻¹ = {(b, a) | (a, b) ∈ f} (กลับด้านทุกคู่). ต้องแสดง 3 อย่าง: (1) f⁻¹ เป็นฟังก์ชัน B → A (2) one-to-one (3) onto A.

  1. f⁻¹ เป็นฟังก์ชันจาก B ไป A: ต้องให้ทุก b ∈ B มีคู่ (b, a) ∈ f⁻¹ พอดี 1 คู่. มีอย่างน้อย 1 เพราะ f onto (ทุก b ถูกชี้จากบาง a). มีไม่เกิน 1 เพราะ f one-to-one (ถ้า (b,a₁),(b,a₂) ∈ f⁻¹ แล้ว f(a₁) = f(a₂) = b ⇒ a₁ = a₂).
  2. f⁻¹ one-to-one: ถ้า f⁻¹(b₁) = f⁻¹(b₂) = a แล้ว (a, b₁), (a, b₂) ∈ f — f เป็นฟังก์ชัน จึง b₁ = b₂.
  3. f⁻¹ onto A: ทุก a ∈ A มี b = f(a) ∈ B ที่ (b, a) ∈ f⁻¹ → a ถูกชี้ถึง.
Since f is onto, every b ∈ B has some a with f(a) = b; since f is one-to-one, this a is unique. Hence f⁻¹ = {(b,a) : f(a) = b} assigns to each b ∈ B exactly one a ∈ A, i.e. f⁻¹ : B → A is a function. It is one-to-one: f⁻¹(b₁) = f⁻¹(b₂) = a implies b₁ = f(a) = b₂. It is onto A: for any a ∈ A, f⁻¹(f(a)) = a. Therefore f⁻¹ is a bijection. ∎
สังเกต: "onto ของ f" ทำให้ f⁻¹ นิยามได้ครบทุก b, "one-to-one ของ f" ทำให้ f⁻¹ ไม่มีสองปลายทาง — สลับบทบาทกัน. อาจารย์วาดใต้สไลด์: 1-to-1 + onto ⇒ f⁻¹ ก็ 1-to-1 + onto.

S4 · equivalence class เท่ากันหรือไม่ซ้อนกันrelation

สไลด์ Ch.1 หน้า 29 · ใกล้เคียงข้อสอบ: ชุด 4 ข้อ 7.2 (equivalence)
โจทย์: Let R be an equivalence relation on A. Show that for any a, b ∈ A, either [a]R = [b]R or [a]R ∩ [b]R = ∅.

นิยาม

[a]R = {x ∈ A | (a, x) ∈ R} = "กลุ่มของ a". R เป็น equivalence: reflexive, symmetric, transitive.

วิธีคิด

ถ้าสองกลุ่มมีสมาชิกร่วมกันสักตัว c จะบังคับให้ a กับ b สัมพันธ์กัน แล้วกลุ่มทั้งสองจะกลายเป็นกลุ่มเดียวกัน. (อาจารย์วาด: (a,b) ∈ R → [a] = [b]; (a,b) ∉ R → [a] ≠ [b] และแยกกัน)

Suppose [a] ∩ [b] ≠ ∅; pick c ∈ [a] ∩ [b], so (a,c) ∈ R and (b,c) ∈ R. By symmetry (c,b) ∈ R; by transitivity (a,b) ∈ R, and by symmetry (b,a) ∈ R.
Now let x ∈ [a], i.e. (a,x) ∈ R. From (b,a) ∈ R and transitivity, (b,x) ∈ R, so x ∈ [b]. Hence [a] ⊆ [b]. The same argument with a and b exchanged gives [b] ⊆ [a]. Therefore [a] = [b].
So either the classes are disjoint or they coincide. ∎
ต้องใช้ทั้ง symmetric และ transitive — บอกให้ชัดว่าใช้ตรงไหน. reflexive ใช้ตอนบอกว่า a ∈ [a] (กลุ่มไม่ว่าง) ใน S5.

S5 · A/R เป็น partitionrelation

สไลด์ Ch.1 หน้า 30 · ใกล้เคียงข้อสอบ: ชุด 3 ข้อ 1(d)(e), ชุด 4 ข้อ 6.1 (partition)
โจทย์: Let R be an equivalence relation on A and A/R = {[a]R | a ∈ A}. Prove that A/R is a partition of A.

ต้องเช็ค 3 เงื่อนไขของ partition

  1. ไม่มีบล็อกว่าง: a ∈ [a] เสมอ เพราะ (a,a) ∈ R (reflexive) → ทุกกลุ่มมีสมาชิกอย่างน้อย 1
  2. บล็อกไม่ซ้อนกัน: จาก S4 กลุ่มสองกลุ่มที่ต่างกันต้อง disjoint
  3. รวมกันได้ A: ทุก a ∈ A อยู่ใน [a] ∈ A/R → ⋃ A/R ⊇ A; และทุกกลุ่มเป็น subset ของ A → ⋃ A/R ⊆ A
(1) For every a ∈ A, (a,a) ∈ R by reflexivity, so a ∈ [a]; thus no member of A/R is empty. (2) By the previous property, two classes are either equal or disjoint, so distinct members of A/R are disjoint. (3) Each a ∈ A belongs to [a] ∈ A/R, hence ⋃A/R = A. Therefore A/R is a partition of A. ∎

ภาพจากสไลด์: นักเรียน/สัญชาติเดียวกัน = แบ่งเป็นกลุ่มสัญชาติ ไม่มีกลุ่มว่าง ไม่มีใครอยู่สองกลุ่ม.

S6 · ข้อเท็จจริง 3 ข้อเรื่องการนับcountability

สไลด์ Ch.1 หน้า 35 · ใกล้เคียงข้อสอบ: ชุด 4 ข้อ 1, 6.2, 9.3
โจทย์: Prove: (1) Every subset of a finite set is finite. (2) Every subset of a countably infinite set is finite or countably infinite. (3) ℕ × ℕ is countably infinite.

(1) subset ของเซตจำกัด

A จำกัด = มี bijection กับ {1,…,n}. ให้ B ⊆ A. เรียงสมาชิกของ A เป็น a₁,…,aₙ แล้วเก็บเฉพาะตัวที่อยู่ใน B ตามลำดับเดิม ได้ b₁,…,bm โดย m ≤ n → B มี bijection กับ {1,…,m} → จำกัด. (พิสูจน์แบบ induction บน n ก็ได้: ตัด aₙ ออกทีละตัว)

(2) subset ของเซตนับได้อนันต์

A = {a₀, a₁, a₂, …} (มี bijection กับ ℕ). ให้ B ⊆ A. ถ้า B จำกัดจบ. ถ้า B อนันต์: นิยาม f : ℕ → B โดย f(0) = สมาชิกของ B ที่มี index เล็กสุด, f(k+1) = สมาชิกของ B ที่ index เล็กสุดที่มากกว่า index ของ f(k). มีอยู่เสมอเพราะ B อนันต์. f one-to-one (index เพิ่มเสมอ) และ onto B (ทุก b = aⱼ ถูกเลือกภายใน j+1 ขั้น) → B countably infinite. ∎ นี่คือ "เรียงตามลำดับเดิม ข้ามตัวที่ไม่อยู่".

(3) ℕ × ℕ นับได้ — dovetailing

เดินทแยงตามผลรวม i+j: (0,0) · (0,1),(1,0) · (0,2),(1,1),(2,0) · … ทุกคู่ (i,j) อยู่ในแนวทแยงที่ i+j ซึ่งมีจำกัด (i+j+1 คู่) จึงถูกนับถึงในเวลาจำกัด. สูตรตรง: f(i,j) = (i+j)(i+j+1)/2 + i เป็น bijection ℕ×ℕ → ℕ. อาจารย์เขียนโค้ดใต้สไลด์: for i in range(1000): for j in range(1000): print((i,j), 1000*i + j) — นั่นเป็นภาพของกรณีจำกัด; สำหรับอนันต์ต้องใช้ทแยง (ถ้าไล่ i=0 ทุก j ก่อน จะไม่มีวันถึง i=1).

Define f : ℕ×ℕ → ℕ by f(i,j) = (i+j)(i+j+1)/2 + i. Pairs are enumerated diagonal by diagonal (i+j = 0, 1, 2, …); within the diagonal i+j = d there are d+1 pairs numbered by i, and all diagonals before it contribute d(d+1)/2 numbers. Hence f is a bijection and ℕ×ℕ is countably infinite. ∎

S7 · Induction 2 ข้อinduction

สไลด์ Ch.1 หน้า 37 · ใกล้เคียงข้อสอบ: — (proof technique)
โจทย์: (1) Prove that 1 + 2 + ⋯ + n = n(n+1)/2. (2) Suppose f, g : ℕ → ℕ \ {0} satisfy g(0) ≤ f(0) and, for each n ≥ 0, g(n+1)/g(n) ≤ f(n+1)/f(n). Then for any n ≥ 0, g(n) ≤ f(n).

โครง induction (ท่อง)

Basis: ตรวจ n = 0 (หรือค่าเริ่ม). Hypothesis: สมมติจริงสำหรับ n. Step: แสดงว่าจริงสำหรับ n+1 โดยใช้สมมติฐาน.

(1) ผลบวก

Basis (n = 0): left side is the empty sum 0, right side is 0·1/2 = 0. ✓
Hypothesis: assume 1 + ⋯ + n = n(n+1)/2.
Step: 1 + ⋯ + n + (n+1) = n(n+1)/2 + (n+1) = (n+1)(n/2 + 1) = (n+1)(n+2)/2, which is the formula for n+1. ∎

(2) อัตราส่วน

ความหมาย: g เริ่มต่ำกว่า f และ "โตช้ากว่าหรือเท่ากับ" f ในทุกก้าว (อัตราส่วนการโต) → g ไม่มีวันแซง f. ค่าเป็นบวกทั้งหมด (ℕ \ {0}) จึงคูณไขว้ได้โดยไม่กลับเครื่องหมาย.

Basis: g(0) ≤ f(0) is given.
Hypothesis: assume g(n) ≤ f(n).
Step: from g(n+1)/g(n) ≤ f(n+1)/f(n) and g(n), f(n) > 0 we get g(n+1) ≤ g(n)·f(n+1)/f(n). By the hypothesis g(n) ≤ f(n), so g(n)·f(n+1)/f(n) ≤ f(n)·f(n+1)/f(n) = f(n+1). Hence g(n+1) ≤ f(n+1). ∎
ข้อ (2) ต้องอ้างว่า f(n), g(n) > 0 ก่อนคูณอสมการ — นั่นคือเหตุผลที่โจทย์ให้ co-domain เป็น ℕ \ {0}.

S8 · Pigeonhole 3 ข้อpigeonhole

สไลด์ Ch.1 หน้า 38 · ใกล้เคียงข้อสอบ: ชุด 1 ข้อ 15, ชุด 4 ข้อ 4
โจทย์: (1) 79 students, 70 chairs — can each student get a separate chair? Prove. (2) 5×10⁶ men and 5×10⁶+1 women — can each woman be given a man of her own? Prove. (3) Prove the pigeonhole principle by induction.

หลัก

Pigeonhole: A, B จำกัด, |A| > |B| ⇒ ไม่มีฟังก์ชัน one-to-one จาก A ไป B. "ให้แต่ละคนแยกกัน" = ฟังก์ชัน one-to-one จากคนไปเก้าอี้.

  1. 79 คน 70 เก้าอี้: ไม่ได้. การจัดที่นั่งคือ f : Students → Chairs; "แยกกัน" คือ one-to-one. |Students| = 79 > 70 = |Chairs| → pigeonhole บอกว่าไม่มี f แบบนั้น → อย่างน้อย 2 คนต้องใช้เก้าอี้ตัวเดียวกัน.
  2. ผู้หญิง 5×10⁶+1 ผู้ชาย 5×10⁶: ไม่ได้ ด้วยเหตุผลเดียวกัน: f : Women → Men one-to-one เป็นไปไม่ได้เพราะ |Women| = |Men| + 1 > |Men| → มีผู้หญิง 2 คนได้ผู้ชายคนเดียวกัน. (ตัวเลขใหญ่ไม่เกี่ยว — ต่างกันแค่ 1 ก็พอ)
  3. พิสูจน์ pigeonhole ด้วย induction บน |B| (ตาม textbook หน้า 25–26 และ trick ที่อาจารย์เขียน):
Claim: for all finite A, B with |A| > |B| there is no one-to-one f : A → B. Induction on n = |B|.
Basis n = 0: B = ∅ and A ≠ ∅, so there is no function A → B at all.
Hypothesis: the claim holds whenever |B| ≤ n.
Step: let |B| = n+1, |A| > n+1, and suppose f : A → B is one-to-one. Pick any e ∈ A. Let A′ = A − {e}, B′ = B − {f(e)}; then |A′| = |A| − 1 > n = |B′|. Since f is one-to-one, no other element of A maps to f(e), so the restriction f′ : A′ → B′ is a one-to-one function — contradicting the hypothesis for |B′| = n. Hence no such f exists. ∎
จุดสำคัญในขั้น step: ต้องบอกว่า "f one-to-one ⇒ ตัด e กับ f(e) ออกแล้ว ที่เหลือยังเป็นฟังก์ชัน A′ → B′" (ไม่มีใครอื่นชี้ไป f(e)). อาจารย์เขียนเป็น 4 ข้อ: FACT |B|=0 ไม่มี 1-to-1 → assume f → remove e, f(e) → ลดจนถึง |B| = 0.

S11 · Σ* กับ 2^Σ* นับได้ไหมcountability

สไลด์ Ch.1 หน้า 45 · ใกล้เคียงข้อสอบ: ชุด 1 ข้อ 4(d)/6, ชุด 2 ข้อ 7, ชุด 4 ข้อ 9.1, 20
โจทย์: Is Σ* countably infinite? And is 2Σ* countably infinite?

Σ* — countably infinite ✓

อนันต์: มี a, aa, aaa, … ไม่ซ้ำ. นับได้: เรียงทุก string ตามความยาวก่อน แล้วภายในความยาวเดียวกันเรียงตามลำดับตัวอักษร (lexicographic): e; a, b; aa, ab, ba, bb; aaa, … แต่ละความยาว k มี |Σ|k string จำกัด จึงทุก string ถูกนับถึงในขั้นจำกัด → bijection กับ ℕ. (อาจารย์เขียนอีกวิธี: ถ้า Σ = {0,1} มอง string เป็นเลขฐานสอง — แต่ต้องระวัง 0 นำหน้า จึงใช้วิธีเรียงตามความยาวปลอดภัยกว่า)

2Σ* — ไม่นับได้ (uncountable) ✗

2Σ* = เซตของทุกภาษา. ใช้ diagonalization: สมมติเรียงภาษาทั้งหมดได้ L₀, L₁, L₂, … และเรียง string ได้ w₀, w₁, w₂, … (จากข้างบน). สร้าง D = {wᵢ | wᵢ ∉ Lᵢ}. D เป็นภาษา จึงต้องเป็น Lk บางตัว — แต่ wk ∈ D ⇔ wk ∉ Lk = D ขัดแย้ง. ดังนั้นเรียงไม่ได้. (ทางลัด: Σ* ≈ ℕ ⇒ 2Σ* ≈ 2ℕ ซึ่ง uncountable ตาม Theorem 1.5.2)

Σ* is countably infinite: list strings by increasing length and, within each length, lexicographically; every string appears at a finite position. 2Σ* is uncountable: it is equinumerous with 2ℕ (via the bijection Σ* ↔ ℕ), and 2ℕ is uncountable by the diagonalization principle. ∎

S12 · Regular ⇔ regex และ monotonicityregex

สไลด์ Ch.1 หน้า 51 · ใกล้เคียงข้อสอบ: ชุด 1 ข้อ 9, ชุด 2 ข้อ 7
โจทย์: (1) Prove: A language A is regular iff there exists a regular expression α with A = L(α). (2) Show that Kleene star, concatenation and union are monotonic: if L₀ ⊆ L₁ then L₀* ⊆ L₁*, L₀L ⊆ L₁L, L₀ ∪ L ⊆ L₁ ∪ L.

(1) ทำไม "regular" กับ "มี regex" เป็นสิ่งเดียวกัน

นิยาม regular languages (สไลด์) = เซตเล็กที่สุด R ที่มี ∅, {a} และปิดภายใต้ ∪, ·, *. ให้ E = {L(α) | α regex}.

  1. E ⊆ R (ทุก regex ให้ภาษา regular): induction บนโครงสร้างของ α. Basis: L(∅) = ∅ ∈ R, L(a) = {a} ∈ R. Step: ถ้า L(α), L(β) ∈ R แล้ว L(αβ) = L(α)L(β), L(α∪β) = L(α) ∪ L(β), L(α*) = L(α)* อยู่ใน R เพราะ R ปิดภายใต้ 3 op.
  2. R ⊆ E (ทุกภาษา regular มี regex): E มี ∅, {a} (จาก regex ∅, a) และปิดภายใต้ 3 op (ถ้า A = L(α), B = L(β) แล้ว AB = L(αβ) ฯลฯ). R เป็นเซตเล็กที่สุดที่มีคุณสมบัตินี้ → R ⊆ E. ∎

(2) monotonic

Assume L₀ ⊆ L₁.
(a) Let w ∈ L₀*; then w = w₁⋯wk with k ≥ 0 and each wᵢ ∈ L₀ ⊆ L₁, so w ∈ L₁*.
(b) Let w ∈ L₀L; then w = xy with x ∈ L₀ ⊆ L₁ and y ∈ L, so w ∈ L₁L.
(c) Let w ∈ L₀ ∪ L; then w ∈ L₀ ⊆ L₁ or w ∈ L, so w ∈ L₁ ∪ L. ∎

ใช้ทำอะไร: ตอบข้อ "⊆" ของภาษาได้ทันที เช่น L((ab)*) ⊆ L((a∪b)*) เพราะ {ab} ⊆ {a,b}* แล้ว star รักษา ⊆.

(a) (⊆) Let x ∈ A ∪ (B∩C). Case x ∈ A: then x ∈ A∪B and x ∈ A∪C. Case x ∈ B∩C: then x ∈ B ⊆ A∪B and x ∈ C ⊆ A∪C. Either way x ∈ (A∪B)∩(A∪C). (⊇) Let x ∈ (A∪B)∩(A∪C). If x ∈ A we are done. Otherwise x ∈ B (from x ∈ A∪B) and x ∈ C (from x ∈ A∪C), so x ∈ B∩C ⊆ A∪(B∩C). ∎
(b) (⊆) x ∈ A and x ∈ B∪C: if x ∈ B then x ∈ A∩B, else x ∈ C and x ∈ A∩C. (⊇) x ∈ A∩B or x ∈ A∩C; in both cases x ∈ A and x ∈ B∪C. ∎
(c) (⊆) A∩(A∪B) ⊆ A trivially. (⊇) x ∈ A ⇒ x ∈ A∪B ⇒ x ∈ A∩(A∪B). ∎
(d) (⊇) A ⊆ A∪(A∩B) trivially. (⊆) x ∈ A∪(A∩B) ⇒ x ∈ A or x ∈ A∩B ⊆ A ⇒ x ∈ A. ∎

ไอเดีย: ฟังก์ชัน 0/1 = "ติ๊กถูก" ว่าเอาสมาชิกไหนบ้าง

ฟังก์ชัน f : A → {0,1} คือการตอบ "ใช่/ไม่ใช่" ให้แต่ละ a ∈ A. เก็บตัวที่ตอบ 1 ได้ subset หนึ่งของ A; กลับกัน subset S ให้ฟังก์ชัน "characteristic function" χS(a) = 1 ถ้า a ∈ S, 0 ถ้าไม่.

1.3.5 · kernel ของฟังก์ชันเป็น equivalencerelation

Reflexive: f(a) = f(a), so (a,a) ∈ R for all a.
Symmetric: if f(a) = f(b) then f(b) = f(a), so (a,b) ∈ R implies (b,a) ∈ R.

textbook หน้า 20 · ใกล้เคียงข้อสอบ: ชุด 1 ข้อ 15 (เฉลยอาจารย์อ้างข้อนี้ตรง ๆ)

1.5.2 · n⁴ − 4n² หาร 3 ลงตัวinduction

textbook หน้า 29 · ใกล้เคียงข้อสอบ: —
โจทย์: Show by induction that n⁴ − 4n² is divisible by 3 for all n ≥ 0.
Basis n = 0: 0 − 0 = 0 = 3·0. ✓
Hypothesis: 3 | n⁴ − 4n², say n⁴ − 4n² = 3m.
Step: (n+1)⁴ − 4(n+1)² = (n⁴ + 4n³ + 6n² + 4n + 1) − (4n² + 8n + 4) = (n⁴ − 4n²) + (4n³ + 6n² − 4n − 3) = 3m + 4n³ + 6n² − 4n − 3.
It remains to show 3 | 4n³ + 6n² − 4n − 3 = 3(2n² − 1) + 4(n³ − n). Now n³ − n = (n−1)n(n+1) is a product of three consecutive integers, one of which is a multiple of 3. Hence the whole expression is divisible by 3. ∎
ทางลัดไม่ใช้ induction: n⁴ − 4n² = n²(n² − 4) = n²(n−2)(n+2) และ n−2, n, n+2 มีตัวหนึ่งหาร 3 ลงตัว (เพราะ n−2 ≡ n+1 mod 3) — เขียนเป็น "alternative" ได้ แต่โจทย์สั่ง induction.

1.5.11 · [0,1] นับไม่ได้ (Cantor)diagonalization

textbook หน้า 29 · ใกล้เคียงข้อสอบ: ชุด 4 ข้อ 4, 9.1
โจทย์: Show that the set of real numbers in [0,1] is uncountable. (Hint: write each number in binary as an infinite 0/1 sequence; assume an enumeration exists and flip the i-th bit of the i-th sequence.)
Suppose [0,1] is countable: x₀, x₁, x₂, … lists every number in [0,1]. Write each xᵢ in binary as 0.bᵢ₀bᵢ₁bᵢ₂… (an infinite sequence of bits). Define a new number y = 0.c₀c₁c₂… by cᵢ = 1 − bᵢᵢ (flip the i-th bit of the i-th number). Then y ∈ [0,1] but y differs from every xᵢ in the i-th bit, so y is not in the list — contradiction. Hence [0,1] is uncountable. ∎

นี่คือ diagonalization ตัวเดียวกับ 2ℕ: แถว i = ลำดับบิตของ xᵢ, D = "กลับบิตบนเส้นทแยง". (รายละเอียดทางเทคนิค: บางจำนวนมี 2 การเขียน เช่น 0.1000… = 0.0111… — หลีกเลี่ยงได้โดยไม่ใช้การเขียนที่ลงท้ายด้วย 1 ทั้งหมด; ข้อสอบไม่เจาะจุดนี้)

คำถามชุด 4 ข้อ 4: "เทคนิคไหนใช้พิสูจน์ว่าเซตอนันต์มีขนาดต่างกัน" = diagonalization.

1.7.6 · เมื่อไร L⁺ = L* − {e}ภาษา

textbook หน้า 45 · ใกล้เคียงข้อสอบ: ชุด 1 ข้อ 10(d), ชุด 3 ข้อ 5(d)
โจทย์: Under what circumstances is L⁺ = L* − {e}?

L* = L⁺ ∪ {e} เสมอ (L⁺ = ต่ออย่างน้อย 1 ชิ้น, L* เพิ่มกรณี 0 ชิ้น). ดังนั้น L* − {e} = L⁺ − {e}. สองข้างเท่ากัน ⇔ L⁺ ไม่มี e ⇔ e ∉ L. (ถ้า e ∈ L แล้ว e = e·e… ∈ L⁺ แต่ e ∉ L* − {e}.)

L⁺ = L* − {e} if and only if e ∉ L. Indeed L* = L⁺ ∪ {e} always, so L* − {e} ⊆ L⁺; and L⁺ ⊆ L* − {e} iff e ∉ L⁺ iff e ∉ L (e is a concatenation of strings of L only if all of them are e). ∎
คู่แฝดกับกฎ "L* = LL* ⇔ e ∈ L" ในข้อสอบ: L⁺ = LL*. สรุปสองบรรทัด: e ∈ L → L⁺ = L*; e ∉ L → L⁺ = L* − {e}.

2.1.1 · e ∈ L(M) เมื่อไรDFA

textbook หน้า 60 · ใกล้เคียงข้อสอบ: ชุด 2 ข้อ 10(c) (start เป็น final), ชุด 4 ข้อ 13
โจทย์: Let M be a DFA. Under exactly what circumstances is e ∈ L(M)? Prove your answer.
Claim: e ∈ L(M) if and only if s ∈ F.
By definition, e ∈ L(M) iff (s, e) ⊢* (q, e) for some q ∈ F. Since no symbol can be read from the empty string, the only configuration reachable from (s, e) in zero or more steps is (s, e) itself (a DFA has no e-transitions). Hence (s,e) ⊢* (q,e) forces q = s, and e ∈ L(M) iff s ∈ F. ∎
ใช้ตอบทุกข้อวาด FA: "e อยู่ในภาษาไหม → start ต้องเป็น final ไหม". สำหรับ NFA เงื่อนไขเปลี่ยนเป็น E(s) ∩ F ≠ ∅ (ไปถึง final ด้วย e ได้).

2.4.5 · ไม่ regular ด้วย pumping + ∩pumping

textbook หน้า 90 · ใกล้เคียงข้อสอบ: ชุด 1 ข้อ 16, ชุด 2 ข้อ 11–12
โจทย์: Using the pumping theorem and closure under intersection, show that these are not regular: (a) {wwR : w ∈ {a,b}*} (b) {ww : w ∈ {a,b}*} (c) {w w̄ : w ∈ {a,b}*} where w̄ swaps a ↔ b.

สูตร closure โยนกลับด้วย ∩

ถ้า L regular แล้ว L ∩ R regular สำหรับ R regular ใด ๆ (ปิดภายใต้ ∩). เลือก R เป็น regex ที่ "ตัด" L ให้เหลือรูปง่าย ๆ อย่าง aⁿbⁿ แล้ว pump.

  1. (a) wwR (palindrome ความยาวคู่): R = a*bba* → L ∩ R = {aⁿbbaⁿ | n ≥ 0} (palindrome ที่มี bb ตรงกลางและ a รอบข้างต้องเท่ากัน). Pump: w₀ = aⁿbbaⁿ, y = aᵏ ใน n ตัวแรก, i = 0 → an−kbbaⁿ ไม่ใช่ palindrome → ∉ L ∩ R → L ∩ R ไม่ regular → L ไม่ regular
  2. (b) ww: R = a*ba*b → L ∩ R = {aⁿbaⁿb | n ≥ 0} (ww ที่มี b พอดี 2 ตัว บังคับให้ w = aⁿb). Pump: w₀ = aⁿbaⁿb, y = aᵏ, i = 0 → an−kbaⁿb ครึ่งแรกครึ่งหลังไม่เท่ากัน → ∉
  3. (c) w w̄: R = a*b* → L ∩ R = {aⁿbⁿ | n ≥ 0} (w ต้องเป็น a ล้วนถึงจะไม่มี b ก่อน a; แล้ว w̄ = bⁿ). ไม่ regular ตามพิสูจน์มาตรฐาน
(c) Suppose L = {ww̄} is regular. Since a*b* is regular and regular languages are closed under intersection, L ∩ a*b* = {aⁿbⁿ : n ≥ 0} would be regular. But by the Pumping Theorem (take aⁿbⁿ, y = aᵏ with k ≥ 1, i = 0) it is not. Hence L is not regular. ∎ (ข้อ (a),(b) เขียนแบบเดียวกันโดยเปลี่ยน R และ string)
ทำไมต้อง ∩ ก่อน: ถ้า pump wwR ตรง ๆ ด้วย w₀ = aⁿaⁿ = a2n จะปั๊มแล้วยังเป็น aคู่ ซึ่งเป็น palindrome — ไม่ได้ข้อขัดแย้ง; การ ∩ กับ a*bba* "ล็อกตรงกลาง" ให้การปั๊มทำลายสมมาตร.
