1 · วาด automaton แล้วป้อน string

Automaton คือ "เครื่องอ่านเทป" ที่จำได้แค่ว่าตอนนี้อยู่ state ไหน อ่านสัญลักษณ์ทีละตัวจากซ้ายไปขวา แล้วเปลี่ยน state ตามลูกศร — จบเทปแล้วอยู่ state วงคู่ = accept

ทฤษฎี · DFA / NFA / configuration / ⊢
DFA M = (K, Σ, δ, s, F) — K = เซตของ state (จำกัด), Σ = alphabet, δ : K × Σ → K ฟังก์ชัน (ทุก state + ทุกสัญลักษณ์ มีทางไปทางเดียวเป๊ะ), s = start, F ⊆ K = final states
NFA M = (K, Σ, Δ, s, F) — Δ ⊆ K × (Σ ∪ {e}) × K ความสัมพันธ์: จาก (state, สัญลักษณ์) ไปได้หลายทาง หรือไม่มีทางเลย และมี e-transition = เปลี่ยน state โดยไม่อ่านอะไร

Configuration (q, ω) = (state ปัจจุบัน, input ที่ยังไม่ได้อ่าน). (q, σω′) ⊢M (q′, ω′) เมื่อ δ(q, σ) = q′ ("yields in one step"). ⊢* = ศูนย์ step หรือมากกว่า.

ω ถูก accept iff (s, ω) ⊢* (q, e) สำหรับบาง q ∈ F. L(M) = เซตของ string ที่ accept ทั้งหมด. NFA accept ถ้ามี "อย่างน้อยหนึ่ง" เส้นทางที่ไปถึง F — เครื่องเดาถูกเสมอ.

ข้อสอบชอบถาม: e ∈ L(M) iff s ∈ F (Problem 2.1.1). DFA ที่ไม่มีทางออกสำหรับบางสัญลักษณ์ = ไม่ complete → เพิ่ม trap/dead state (Example 2.1.2 q₃).

2 · NFA → DFA (Powerset construction)

NFA "อยู่หลาย state พร้อมกัน" ได้ — งั้นก็ให้ เซตของ state ทั้งเซตนั้นเป็น state ใหม่ตัวเดียวของ DFA ("superstate") แล้วคำนวณว่าเมื่ออ่านสัญลักษณ์ เซตนั้นย้ายไปเป็นเซตไหน

ทฤษฎี · Theorem 2.2.1 (Rabin–Scott 1959)
E(q) (e-Closure) = {p | (q, e) ⊢* (p, e)} = ทุก state ที่ไปถึงจาก q โดยไม่อ่านอะไรเลย (รวม q เอง). คำนวณโดยวนเพิ่ม r ที่มี (p, e, r) ∈ Δ กับ p ∈ E(q) จนไม่มีอะไรเพิ่ม (≤ |K| รอบ)
M′ = (K′, Σ, δ′, s′, F′): K′ = 2K, s′ = E(s), F′ = {Q ⊆ K | Q ∩ F ≠ ∅}, δ′(Q, σ) = ⋃{ E(p) | q ∈ Q, (q, σ, p) ∈ Δ }

แนวคิดพิสูจน์ (induction on |ω|): (q, ω) ⊢*M (p, e) iff (E(q), ω) ⊢*M′ (P, e) โดย p ∈ P. ดังนั้น ω ∈ L(M) iff s′ ไปถึง P ∈ F′ iff ω ∈ L(M′).

สร้างเฉพาะ superstate ที่ ไปถึงได้จาก s′ (worklist) — ไม่ต้องสร้างทั้ง 2|K|. แต่ worst case ยังเป็น exponential จริง (Example 2.2.5: ภาษา "มีสัญลักษณ์บางตัวไม่ปรากฏ" NFA n+1 state → DFA ต้องมี 2n state).

3 · ย่อ DFA ให้เล็กที่สุด

สอง state "เหมือนกัน" ถ้าไม่ว่าจะป้อน string อะไรต่อจากนี้ ผลลัพธ์ accept/reject เหมือนกันเสมอ — เริ่มจากแบ่งเป็น 2 กลุ่ม (final / ไม่ final) แล้วค่อย ๆ แยกกลุ่ม เมื่อเจอสัญลักษณ์ที่พาไปคนละกลุ่ม จนแยกไม่ได้อีก

ทฤษฎี · ≡ₙ, Lemma 2.5.1, Myhill–Nerode
L′p = ภาษาที่ accept ถ้าเริ่มจาก p. p ≡ q iff L′p = L′q. p ≡n q iff เหมือนกันสำหรับทุก string ยาว ≤ n. ≡₀ ⊇ ≡₁ ⊇ … ⊇ ≡ และเพราะ K จำกัด จึงหยุดนิ่งภายใน |K|−1 รอบ
Lemma 2.5.1 p ≡n+1 q iff (a) p ≡n q และ (b) ทุก a ∈ Σ: δ(p,a) ≡n δ(q,a) — นี่คือกฎที่ใช้ "แยกกลุ่ม" แต่ละรอบ

Myhill–Nerode (Theorem 2.5.2): x ≈L y iff ทุก z: xz ∈ L ⇔ yz ∈ L. จำนวน class ของ ≈L = จำนวน state ต่ำสุดที่เป็นไปได้ และ L regular iff class มีจำกัด — ใช้พิสูจน์ว่า aⁿbⁿ ไม่ regular ได้อีกทาง ([e],[a],[aa],… ไม่ซ้ำกันเลย). ไม่มีในสไลด์ แต่มีใน textbook หน้า 96–98

ก่อน minimize ต้อง (1) ลบ state ที่ไปไม่ถึงจาก s และ (2) ทำให้ complete (มี trap) เพราะ algorithm ใช้ δ(q,a) ทุกคู่. Algorithm นี้ polynomial: O(|K|²·|Σ|·|K|).

4 · Regular expression ↔ Finite automaton

Theorem 2.3.2: ภาษาเป็น regular iff มี FA accept — สองทิศ: RegEx → NFA สร้างจากชิ้นเล็กประกอบใหญ่ (union/concat/star) และ FA → RegEx โดย "ลบ state ทีละตัว" แล้วเขียนฉลากเส้นเป็น regex แทน

ทฤษฎี · Theorem 2.3.1 (closure) · R(i,j,k) · state elimination
RegEx → NFA (Figure 2-14): สัญลักษณ์เดี่ยว = 2 state; concat M₁M₂ = e จากทุก F₁ → s₂; union = s ใหม่ + e → s₁, s₂; star = s ใหม่ (เป็น final ด้วย ให้ accept e) + e → s₁ + e จากทุก F₁ กลับไป s₁
FA → RegEx: R(i,j,k) = string ทั้งหมดที่พาจาก qᵢ ไป qⱼ โดยผ่านเฉพาะ state หมายเลข ≤ k. R(i,j,k) = R(i,j,k−1) ∪ R(i,k,k−1)·R(k,k,k−1)*·R(k,j,k−1) (ไปตรง ๆ หรือ แวะ qₖ กี่รอบก็ได้). L(M) = ⋃ R(1,j,n) สำหรับ qⱼ ∈ F

ในทางปฏิบัติใช้ state elimination (Example 2.3.2): ทำ "special form" (s ใหม่ที่ไม่มีลูกศรเข้า, f ใหม่ตัวเดียวที่ไม่มีลูกศรออก) แล้วลบ state q ทีละตัว: ทุกคู่ qᵢ →α q →β qⱼ (γ = loop ที่ q) เพิ่มเส้น qᵢ → qⱼ ฉลาก δ ∪ αγ*β (Figure 2-17). เหลือ s → f เส้นเดียว = คำตอบ. ลำดับการลบต่างกัน → regex หน้าตาต่างแต่ภาษาเดียวกัน.

ทำไม complement ต้องเป็น DFA? (Problem 2.3.1) เพราะสลับ F ↔ K−F ใน NFA ผิด: string ที่มีทั้ง path accept และ path reject จะถูก accept ทั้งก่อนและหลังสลับ.

        6 · Pumping Theorem — พิสูจน์ว่า "ไม่ regular" ทีละ step

        DFA มี state จำกัด — string ยาวพอต้องวนกลับมา state เดิม ส่วนที่วน (y) จะปั๊มซ้ำกี่รอบก็ยังถูก accept. ถ้าเราหา string ที่ปั๊มแล้ว "หลุด" จากภาษาได้ ⇒ ภาษานั้นมี DFA ไม่ได้ ⇒ ไม่ regular

        ทฤษฎี · Theorem 2.4.1 · ทำไมสรุป "ไม่ regular" ได้
        L regular ⇒ ∃ n ≥ 1 ที่ ทุก ω ∈ L, |ω| ≥ n เขียนได้เป็น ω = xyz โดย y ≠ e, |xy| ≤ n และ xyiz ∈ L ทุก i ≥ 0

        พิสูจน์: n = |K|. อ่าน n ตัวแรกของ ω ผ่าน n+1 configuration แต่มีแค่ n state → มี i < j ที่ qᵢ = qⱼ (pigeonhole). y = ตัวอักษรระหว่างสองจุดนั้น พา qᵢ กลับมา qᵢ จึงตัดออก/ซ้ำได้ไม่จำกัด — และเพราะเราดูแค่ n ตัวแรก จึงได้ |xy| ≤ n

        Logic: theorem บอกว่า regular ⇒ P (ปั๊มได้). เราแสดงว่า ¬P (มี ω ที่ทุกการแบ่งปั๊มแล้วหลุด) ⇒ ¬regular (contrapositive). ใช้พิสูจน์ "ไม่ regular" เท่านั้น — ภาษาบางภาษาไม่ regular แต่ก็ปั๊มได้ theorem จึงพิสูจน์ "regular" ไม่ได้

        กระดาน

        Theorem อ่านเป็น 5 บรรทัด บรรทัดที่สว่าง = step ปัจจุบัน
